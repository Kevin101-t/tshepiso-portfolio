## Troubleshooting

### Website Not Appearing in Google

**Wait:** It can take 2-4 weeks for Google to index new websites

**Speed Up:**
1. Submit sitemap to Google Search Console
2. Request indexing in Search Console
3. Ensure robots.txt allows indexing
4. Check meta tags are correct

### Domain Issues

**If domain isn't working:**
1. Check DNS settings
2. Verify domain is pointing to correct server
3. Wait 24-48 hours for DNS propagation
4. Contact your domain registrar for help

### Content Not Updating

**If changes don't appear:**
1. Clear browser cache (Ctrl+Shift+Delete)
2. Hard refresh page (Ctrl+F5)
3. Wait a few minutes for deployment
4. Check browser console for errors
