# How to Edit Your Website & Add Certificates

## Part 1: How to Edit Your Website

### Option A: Using the Visual Editor (Easiest)

**Steps:**
1. Go to the Management UI (right panel in Manus)
2. Click on the **"Preview"** tab
3. In the preview, **click on any element** you want to edit (text, colors, spacing, etc.)
4. A visual editor will appear on the right side
5. Make your changes in real-time
6. Click **"Save"** to apply changes
7. Changes are automatically saved to a checkpoint

**What You Can Edit:**
- Text content (names, descriptions, titles)
- Colors and backgrounds
- Spacing and padding
- Font sizes
- Button styles
- Hover effects

### Option B: Using the Code Editor

**Steps:**
1. Go to the Management UI
2. Click on the **"Code"** tab
3. Navigate to `client/src/pages/Home.tsx`
4. Find the section you want to edit
5. Make your changes directly in the code
6. Save the file (Ctrl+S)
7. Changes appear live on the preview

**Common Sections to Edit:**
- **About Section:** Search for "About Me"
- **Skills Section:** Search for "Skills & Competencies"
- **Contact Information:** Search for "Get in Touch"
- **Footer:** Search for "Footer"

### Option C: Using the Management UI Settings

**Steps:**
1. Click **"Settings"** in the Management UI
2. Go to **"General"** tab
3. Edit website name, description, favicon
4. Changes apply immediately

## Part 2: How to Add Certificates When You Get Them

### Step-by-Step Instructions

**1. Navigate to Certificates Section**
   - Open your website
   - Scroll down to the **"Certifications & Achievements"** section
   - Or click **"Certificates"** in the navigation menu

**2. Unlock the Editor**
   - Click the **"Add Certificate"** button
   - A password prompt will appear
   - Enter password: `tshepiso2026`
   - You'll see the "Add Certificate" form

**3. Fill in Certificate Details**
   - **Certificate Name:** Enter the full name of your certificate
     - Example: "AWS Solutions Architect Associate"
   - **Issuing Organization:** Enter who issued it
     - Example: "Amazon Web Services"
   - **Date:** Enter when you received or will receive it
     - Example: "June 2026" or "Expected: June 2026"

**4. Save the Certificate**
   - Click the **"Save"** button (green checkmark)
   - Certificate appears immediately on your website
   - Data is saved locally on your device

**5. Manage Your Certificates**
   - **Edit:** Click the "Edit" button on any certificate card
   - **Delete:** Click the "Delete" button to remove a certificate
   - **Logout:** Click "Logout" to exit edit mode

## Part 4: Where to Make Different Edits

### Navigation Menu
- **Location:** Top of page
- **Edit:** Use Code Editor > Home.tsx > Search "Navigation"
- **What to change:** Menu items, links, styling

### Hero Section
- **Location:** Large banner at top with your introduction
- **Edit:** Use Visual Editor or Code Editor > Search "Hero Section"
- **What to change:** Title, description, button text, background image

### About Section
- **Location:** Below hero section
- **Edit:** Visual Editor or Code Editor > Search "About Me"
- **What to change:** Bio, strengths, key points

### Timeline (Journey)
- **Location:** Middle of page
- **Edit:** Code Editor > Search "timelineEvents"
- **What to change:** Add education, experience, achievements

### Skills Section
- **Location:** Below timeline
- **Edit:** Visual Editor or Code Editor > Search "Skills & Competencies"
- **What to change:** Add/remove skills, update proficiency percentages

### Certificates Section
- **Location:** After skills
- **Edit:** Use the built-in "Add Certificate" button (password protected)
- **What to change:** Add new certificates as you complete them

### Contact Section
- **Location:** Near bottom
- **Edit:** Visual Editor or Code Editor > Search "Get in Touch"
- **What to change:** Email, phone, social media links

### Footer
- **Location:** Very bottom
- **Edit:** Code Editor > Search "Footer"
- **What to change:** Copyright notice, social links, contact info

## Part 5: Saving Your Changes

### Automatic Saving
- Changes in the visual editor are saved automatically
- Code changes are saved when you press Ctrl+S

### Creating Checkpoints
- Go to Management UI > **"Dashboard"**
- Click **"Save Checkpoint"**
- Add a description of your changes
- You can rollback to any checkpoint if needed

### Publishing Changes
- After making changes, click **"Publish"** button
- Your live website updates with new changes
- Changes appear immediately for visitors

## Part 6: Troubleshooting

### Changes Not Appearing
- **Solution 1:** Hard refresh your browser (Ctrl+Shift+Delete, then Ctrl+F5)
- **Solution 2:** Wait 30 seconds for changes to deploy
- **Solution 3:** Check browser console for errors

### Can't Add Certificates
- **Solution 1:** Make sure you enter the correct password: `tshepiso2026`
- **Solution 2:** Clear browser cache and try again
- **Solution 3:** Use a different browser

### Dark Mode Text Disappearing
- **Solution 1:** Hard refresh the page
- **Solution 2:** Clear browser cache
- **Solution 3:** Try a different browser

### Toggle Button Too Small
- The toggle has been increased to 15% larger
- If still too small, you can edit the size in Code Editor
